

# Data Visualizations


---

## Overview / Description

This repository showcases a diverse collection of interactive data visualizations and dashboards, illustrating insights across various domains such as **global CO₂ emissions**, **earthquake patterns**, **sales performance**, **COVID-19 geographic spread**, and more. Created with business intelligence tools including *Tableau* and *Power BI*, these dashboards are designed for delivering data-driven insights in a visually intuitive format.

**Use Cases:**

* Presenting environmental trends with global CO₂ emissions dashboards
* Monitoring real-time or historical earthquake data through map-based visuals
* Analyzing retail sales, work order backlogs, and performance over time via interactive BI visuals
* Displaying COVID-19 spread geographically for epidemiological insights

---

## Features

* Clean, interactive dashboards using *Tableau* (`.twbx` files) and *Power BI* (`.pbix` files)
* Visual assets and screenshots for quick previews
* Covers themes like emissions, natural disasters, and business performance metrics
* Designed for analysis, reporting, and storytelling

---

## Installation Instructions

> These dashboards are primarily meant for viewing or presenting. To open and interact with them, follow these steps:

```bash
# 1. Clone the repo:
git clone https://github.com/Damilare-05/Data-Visualizations.git
cd Data-Visualizations

# 2. Ensure you have the required BI tool installed:
#   - For Tableau files (.twbx): Install Tableau Reader or Tableau Desktop
#   - For Power BI files (.pbix): Install Power BI Desktop

# 3. Open any file:
# Example for Tableau:
tableau-desktop Earthquakedashboard.twbx

# Example for Power BI:
# Open Power BI Desktop → File → Open → select "SalesOrderDashboard.pbix"
```

## Usage

### Opening a Dashboard

1. Open *Tableau Reader* or *Tableau Desktop*, then open `Earthquakedashboard.twbx` to explore earthquake patterns via maps and timelines.
2. Launch *Power BI Desktop*, then open `SalesOrderDashboard.pbix` to interact with sales performance dashboards—filter by date ranges, categories, and explore breakdowns.

Included screenshots (e.g., `Screenshot 2024-08-16 133027.png`) provide quick glimpses of key dashboards, giving a feel of layout, visual styling, and interactivity.
